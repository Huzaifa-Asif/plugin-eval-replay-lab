# Privacy

Plugin Eval Replay Lab processes fixture text in the current browser tab or local CLI process. It has no analytics, cookies, account, remote API, persistent storage, or third-party asset. The hosted static files are delivered by GitHub Pages, whose infrastructure receives ordinary request metadata such as IP address and user agent.

Use synthetic or explicitly redacted fixtures. Do not enter credentials, authentication headers, personal records, production prompts, proprietary tool output, or regulated data. Reports intentionally include only case identifiers, finding codes, paths, counts, and fixed explanations.

Retention is zero within the application: reloading or closing the page clears entered content. The CLI writes only when the caller redirects its output.
